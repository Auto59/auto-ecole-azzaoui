#Auto_Ecole_Azzaoui

موقع إلكتروني احترافي لشركة Auto Ecole Azzaoui لتعليم السياقة.

## التشغيل محلياً

1. افتح المجلد في المتصفح مباشرةً على ملف `index.html`، أو
2. تشغيل خادم محلي مثل:

```bash
python3 -m http.server 8000
```

ثم افتح الرابط التالي في المتصفح:

```text
http://localhost:8000
```

## ملاحظات

- تم تصميم الموقع ليكون متجاوباً على الجوال والكمبيوتر.
- يحتوي على أقسام رئيسية مثل: الرئيسية، الخدمات، الأسعار، التواصل.
- يوجد زر واتساب سريع للوصول إلى التواصل المباشر.
